What is a class?

A class is a template for creating objects. Objects contain properties (information) and methods (functions).

Properties: Store values, such as a name or age.

Methods: Perform actions using those values.

Example 1: Animal

Enter a name and age, then create an animal.

Example 2: Rectangle

Use a class method to calculate the area.

Example 3: Counter

Use methods to increase or reset an object's value.

Example Code

JavaScript · Animal class 
class Animal {
  constructor(name, age) {
    this.name = name;
    this.age = age;
  }

  showInfo() {
    return `Hello ${this.name}, you are ${this.age} years old.`;
  }
}

const myDog = new Animal("Snickers", 4);

console.log(myDog.showInfo());

Constructor: Sets the properties. Method: Uses the properties. new: Creates an object from the class.
