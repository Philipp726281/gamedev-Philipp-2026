Core Code Example

The basic idea of extending a class: reuse existing properties and add a new method. 

class Animal {
    constructor(name) {
        this.name = name;
    }
}

class Dog extends Animal {
    speak() {
        return this.name + ' says Woof!';
    }
}

let myDog = new Dog('Buddy');
myDog.speak();
