The Mandelbrot Fractal

The Mandelbrot set consists of complex numbers C for which the sequence remains bounded when repeatedly applying the function, starting with Z = 0.

Zn+1 = Zn2 + C

How it works:

  • Each pixel represents a complex number.
  • We repeatedly square Z and add C.
  • Points that remain bounded are colored black.
  • Points that escape receive colors based on their iteration count.
